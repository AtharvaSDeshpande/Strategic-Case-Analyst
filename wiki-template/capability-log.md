# Capability log

One entry per run: which analytical skill or discipline the work actually required and sharpened.
Be specific about what was genuinely hard or newly needed. Do not restate the run's concept
summary. Appended during Ingest. Never rewritten.

Suggested entry shape:

```
## <run id or date>
**Sharpened:** <the discipline, stated so it transfers to a different subject>
**Trigger:** <what in the work forced it>
```
