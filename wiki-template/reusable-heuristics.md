# Reusable heuristics

Judgment rules earned from real analysis, written so a later run can apply them directly without
re-deriving them. Not every run produces one. Do not manufacture an entry to fill the file.

Every entry records where it came from, how confident it is, and whether a human has validated it.
Repetition across runs is not evidence: an assertion repeated in several runs is still an
assertion until someone checks it.

Suggested entry shape:

```
## <the rule, in one sentence>
**Provenance:** <which runs produced it>
**Confidence:** low | medium | high
**Human-validated:** yes | no
**Applies when:** <the conditions under which it holds>
```
